# Actividad AWS - Ingeniería de Datos

La carpeta raíz es el proyecto de entrega. Contiene el código, las evidencias, el documento final y el PDF
de la actividad.

## Antes de entregar

1. Leer [`ESTADO.md`](ESTADO.md) y completar los puntos que aún aparecen como pendientes.
2. Ejecutar cada punto desde esta carpeta y ejecutar su operación `limpiar` al terminar.
3. Regenerar el documento con:

   ```bash
   uv run python documento/generar_documento.py --autor "Nombres de los integrantes"
   ```

4. Entregar esta carpeta excluyendo `.venv/`, `.estado/`, `.terraform/`, estados de Terraform,
   llaves privadas, credenciales y archivos `.env`.

La carpeta `material_previo/` conserva las carpetas antiguas como respaldo y no debe mezclarse con la
evidencia final.
